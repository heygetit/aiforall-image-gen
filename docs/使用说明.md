# 使用说明

本插件固定访问 `aiforall.me` Images API。完整命令和示例见仓库根目录 `README.md`。

## 默认行为

- 模型：`gpt-image-2`
- 质量：`medium`
- 尺寸：`auto`
- 格式：PNG
- 输出：当前项目的 `aiforall-image-gen/`
- 凭据：`AIFORALL_API_KEY` 用于 `gpt-image-2`；`AIFORALL_IMAGE15_API_KEY`/`AIFORALL_IMAGE15_API_KEYS` 用于 `gpt-image-1.5`
- 请求超时：默认且最低 `300` 秒；`AIFORALL_REQUEST_TIMEOUT_SECONDS` 可继续调高。外层命令执行超时应至少为 `360` 秒，且至少比 API 超时多 `60` 秒。

## 透明策略

- `--transparent`：一次 `gpt-image-2` 请求，Pillow 自适应色键验证失败后可使用本地 `rembg`；不会再次请求 API。
- 在线验证结论（2026-07-30）：`gpt-image-1.5` 普通生图可用，但 aiforall.me 当前路由不支持 `background=transparent`；生产透明流程使用 `gpt-image-2 --transparent`。
- `--native-transparent`：仅作为用户确认后的实验性能力探测。服务端返回“不支持透明背景”时标记 `[CAPABILITY-UNAVAILABLE]`，只请求一次且不换 Key；native 池耗尽后同样停止，不自动回退为新的付费请求。
- `--no-rembg` 禁用本地 AI 兜底；`--rembg-model u2net` 选择模型；`--keep-source` 保留原始响应。

## 编辑约束

一个请求最多 16 张输入图。mask 只作用于第一张图，并必须包含 alpha、尺寸一致。`gpt-image-2` 不接受 `input_fidelity`。

## 计费保护

超时、`fetch failed`、断流或响应状态未知的已提交请求标记为 `[NO-RETRY]`。这不代表上游生成失败；图片可能已经生成成功。不要立即重发，先在 aiforall.me 请求历史中查找结果。
